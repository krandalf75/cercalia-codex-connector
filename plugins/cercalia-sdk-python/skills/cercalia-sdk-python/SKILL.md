# Cercalia SDK (Python)

This skill is the entry point for building and maintaining Python applications that use Cercalia SDK services.

## Usage

- Configure your MCP endpoint in \.mcp.json.
- Add the API operations needed by your project (geocoding, routing, matrix, etc.).
- Use Codex and MCP tools to generate and iterate application code in Python.

## Note

This is a starter template. Complete \.mcp.json with your real Cercalia MCP server configuration.
