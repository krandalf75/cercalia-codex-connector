# Cercalia Services

This skill is the entry point for working with Cercalia services from Codex.

## Usage

- Configure the plugin MCP server in `.mcp.json`.
- Expose the operations you need (geocoding, routing, etc.).
- Use MCP tools from Codex to invoke the services.

## Note

This is an initial template. You still need to complete `.mcp.json` with your real Cercalia MCP server configuration.
